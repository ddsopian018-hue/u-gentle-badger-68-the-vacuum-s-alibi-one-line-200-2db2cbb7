# The Vacuum's Alibi

A one-line alibi (160 of the allowed 200 characters) for a vacuum cleaner
accused of a mess it did not make. The defence, delivered straight to the
judge: the crumbs led it there, it only ever follows mess and never makes
it, and the rug's testimony is hearsay from a known dirt collector.

The program is pure-stdlib Python, fully deterministic, and writes the
single line — with no trailing newline — to `entry.txt` in the directory
named by `MAKEFUN_OUTPUT_DIR` (falling back to `/output`).

## Run

```sh
python3 main.py
```
